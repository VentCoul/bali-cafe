# Веб-сайт Кафе з інтеграцією Poster API - Технічна специфікація

## Огляд
Сучасний, SEO-оптимізований e-commerce веб-сайт для кафе, що дозволяє клієнтам переглядати меню (синхронізоване з Poster API) та робити замовлення онлайн для самовивозу або всередині закладу.

## Архітектура та Технологічний Стек
*   **Фреймворк:** Next.js (App Router) для рендерингу на сервері (SSR), оптимізації SEO та вбудованих API-маршрутів.
*   **Frontend UI:** React.js, Tailwind CSS для стилізації та Framer Motion для преміальних мікро-анімацій (ефекти матового скла, плавні переходи).
*   **Бекенд/Інтеграція:** Next.js API Routes будуть діяти як безпечний проксі (Backend-for-Frontend) для Poster API, гарантуючи, що токен доступу Poster ніколи не потрапить до клієнта.
*   **Рекомендації щодо хостингу:** Розгортання на власному VPS сервері клієнта (рекомендується використання Docker для зручності або прямий запуск через Node.js/PM2).

## Основні Функції
### 1. Відображення Меню
*   Категорії (Кава, Десерти, Основні страви тощо) завантажуються з Poster API.
*   "Липка" (sticky) навігація по категоріях під час скролінгу сторінки.
*   Картки товарів з фотографіями, описом, ціною та кнопкою "Додати в кошик".
*   Стратегія кешування для миттєвого завантаження (Next.js ISR - Incremental Static Regeneration).

### 2. Система Кошика
*   Бічна панель (sidebar) або модальне вікно кошика, доступне з будь-якого місця на сайті.
*   Можливість змінювати кількість товарів або видаляти їх.
*   Перерахунок загальної вартості в реальному часі.
*   Управління станом через React Context або Zustand (збереження в local storage).

### 3. Процес Оформлення Замовлення (MVP)
*   **Дані Клієнта:** Ім'я, Номер телефону, Опціональний коментар.
*   **Спосіб отримання:** "В закладі" або "З собою".
*   **Спосіб оплати:** "Оплата при отриманні" (готівкою або карткою). *Онлайн-еквайринг (наприклад, Mono/LiqPay) відкладено для наступних етапів.*
*   **Відправка Замовлення:** Надсилає валідовані дані на наш Next.js API маршрут, який потім передає замовлення до Poster API.

## Потік Даних (Poster API)
1.  **Отримання Меню:** Клієнт запитує меню -> Next.js сервер запитує Poster API -> Next.js кешує та віддає HTML.
2.  **Створення Замовлення:** Клієнт відправляє форму оформлення -> Next.js API отримує дані -> Перевіряє (валідація) -> Надсилає POST-запит до Poster API для створення вхідного замовлення -> Повертає статус "Успіх" клієнту.

## Відкриті Питання та Плани на Майбутнє
*   Інтеграція онлайн-оплати.
*   Дизайн: Буде базуватися на логотипі клієнта та фотографіях страв (очікуються матеріали).
