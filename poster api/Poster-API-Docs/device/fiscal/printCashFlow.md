## onPrintCashFlow: Фискальное внесение/изъятие средств

> Пример использования

```javascript
defaultFiscalPrinter.onPrintCashFlow(async (info, next) => {
    try {
        const { sum, cashier } = info.data;

        // Логика обработки внесения/изъятия
        await processCashFlowChange(sum, cashier);

        next({
            success: true
        });

    } catch (error) {
        next({
            success: false,
            error_message: `Ошибка: ${error.message}`
        });
    }
});
```

Событие срабатывает при выполнении фискального внесения или фискального изъятия наличных на кассе.

#### В `info` содержатся следующие параметры:

| Параметр | Описание                                                |
| -------- | ------------------------------------------------------- |
| `data`   | Объект с данными о фискальной операции внесения/изъятия |
| `device` | Объект фискального устройства, выполняющего операцию    |
| `userId` | Идентификатор пользователя, работающего на кассе        |

#### В `data` содержатся следующие параметры:

| Параметр          | Описание                                                         |
| ----------------- | ---------------------------------------------------------------- |
| `cashier`         | Имя кассира, который выполнил операцию                           |
| `cashier_details` | Дополнительная информация о кассире (может быть пустым объектом) |
| `hash`            | Идентификатор фискальной операции                                |
| `sum`             | Сумма операции: **> 0 — внесение**, **< 0 — изъятие**            |
