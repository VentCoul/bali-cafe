## setDefault: Сделать устройством по умолчанию

> Пример `setDefault` для конкретного устройства по ID:

```javascript
const defaultFiscalPrinter = await Poster.devices.get('id устройства');

defaultFiscalPrinter.setDefault();
```

Метод назначает ваш виртуальный фискальный принтер фискальным регистратором по умолчанию. Это значит, что все фискальные дейсвтия будут отправляться на этот принтер.

!> Лучше выполнять `setDefault()` при каждом запуске вашей интеграции. Так все фискальные действия всегда будут приходить на правильный девайс.
