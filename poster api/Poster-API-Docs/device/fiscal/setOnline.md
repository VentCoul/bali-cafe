## setOnline: Сделать устройство онлайн

> Пример `setOnline` для конкретного устройства по ID:

```javascript
const defaultFiscalPrinter = await Poster.devices.get('id устройства');

defaultFiscalPrinter.setOnline();
```

Метод делает ваш виртульный фискальный регистратор Online, что позволяет вам отправлять на него фискальные действия.

!> Лучше выполнять `setOnline()` при каждом запуске вашей интеграции. Так все фискальные действия всегда будут приходить на правильный девайс.
