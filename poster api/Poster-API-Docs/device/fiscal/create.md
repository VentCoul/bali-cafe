## device.create: Создать фискальный принтер

> Пример создания фискального принтера:

```javascript
const device = await Poster.devices.create({
    deviceClass: 'platformOnlineFiscal',
    name: 'MyFiscalPrinter'
});
```

Метод создаёт виртуальный фискальный принтер.

### Аргументы

Аргумент | Описание
-------- | --------
name | Имя устройства

### Ответ

Функция возвращает `Promise`, который вернет объект созданного устройства с такими свойствами

Свойство | Описание
-------- | --------
applicationId | ID приложения, которое создало девайс
deviceClass | Класс девайса
displayName | Имя девайса, которое клиент увидет в списке устройств на кассе
fiscalCompanyUuid | ID фискальной компании
id | ID устройства
name | Имя устройства
type | Тип устройства

!> Вам нужно создать девайс только один раз. Дальше вы используете все время тот же девайс, делая его `online` и `default`
