## Фискальный принтер

Методы этого раздела позволяют работать с фискальными принтерами, подключенными к кассе Poster. Вы также можете создавать собственные виртуальные фискальные принтеры, для интеграции с вашим фискальным сервисом. Список доступных методов:

- [device.create: Создать фискальный принтер](/docs/v3/device/fiscal/create)
- [devices.getAll: Получить все устройства](/docs/v3/device/fiscal/getAllFiscal)
- [devices.get: Получить устройство](/docs/v3/device/fiscal/getDevice)
- [setDefault: Сделать устройство фискальным принтером по умолчанию](/docs/v3/device/fiscal/setDefault)
- [setOnline: Сделать устройство онлайн](/docs/v3/device/fiscal/setOnline)
- [onPrintFiscalReceipt: Печать фискальнго чека](/docs/v3/device/fiscal/printFiscalReceipt)
- [onPrintFiscalReceipt: Возврат фискальнго чека](/docs/v3/device/fiscal/printFiscalRefund)
- [onPrintXReport: Печать Х-отчета](/docs/v3/device/fiscal/printXReport)
- [onPrintZReport: Печать Z-отчета](/docs/v3/device/fiscal/printZReport)
- [onPrintPeriodicReport: Печать периодического отчета](/docs/v3/device/fiscal/printPeriodicReport)
- [onPrintCashFlow: Фискальное внесение/изъятие средств](/docs/v3/device/fiscal/printCashFlow)
