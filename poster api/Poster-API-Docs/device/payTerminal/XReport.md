## x-report: Печать Х-отчета

> Пример обработки нажатия кнопки Х-балланс на кассе:

```javascript
device.on('x-report', handleXReport); // Подписываемся на событие нажатия кнопки Х-балланс

const handleXReport = (data, next) => {
    const { device } = data;
    
    // Здесь вагша логика снятия Х-отчета на терминале

    next({ success: true });
};
```

Событие срабатывает, когда кассир нажимает кнопку **Х-балланс** на кассе, в блоке **Платежный терминал**.
