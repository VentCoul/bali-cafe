## z-report: Печать Z-отчета

> Пример обработки нажатия кнопки Полный отчет на кассе:

```javascript
device.on('z-report', handleZReport); //Подписываемся на событие нажатия кнопки Полный отчет

const handleZReport = (data, next) => {
    const { device } = data;
    
    // Здесь вагша логика снятия Z-отчета на терминале

    next({ success: true });
};
```

Событие срабатывает, когда кассир нажимает кнопку **Полный отчет** на кассе, в блоке **Платежный терминал**.
