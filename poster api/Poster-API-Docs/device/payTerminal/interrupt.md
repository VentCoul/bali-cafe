## interrupt: Прерывание оплаты

> Пример обработки прерывания оплаты на кассе:

```javascript
device.on('interrupt', handleInterrupt); //подписываемся на событие прервываня оплаты

const handleInterrupt = (data, next) => {
    const { device } = data;
    
    // Здесь вагша логика прерывания оплаты

    next({ success: true });
};
```

При ожидании оплаты картой у кассира есть возможность закрыть окно ожидания оплаты. Событие срабатывает при закрытии этого окна, чтобы отменить оплату на банковском терминале.
