## createPayTerminal: Создать банковский терминал

> Пример ручного создания банковского терминала:

```javascript
const device = await Poster.devices.createPayTerminal({ name: Verifone });
await device.setOnline();
await device.setAuth();
```

Метод создаёт виртуальный банковский терминал.

## Аргументы

Аргумент | Описание
-------- | --------
name | Имя устройства

### Ответ

Функция возвращает `Promise` результат которого объект со следующими свойствами:

Свойство | Описание
-------- | --------
success | Результат, удалось ли создать банковский терминал: `true` — удалось, `false` — не удалось.

!> Используйте `createPayTerminal` только для создания виртуального платежного терминала. Если у вас физический банковский терминал, который можно найти в локальной сети, используйте [validateDevice](/docs/v3/device/payTerminal/validateDevice)

!> Вам нужно создать девайс только один раз. Дальше вы используете все время тот же девайс, делая его `online` и `default`
