## Банковский терминал

Методы этого раздела позволяют работать с банковскими терминалами, подключенными к кассе Poster. Вы можете найти ваш банковский терминал в локальной сети или создать виртуальный платежный терминал вручную, для интеграции с вашим платежным сервисом. 
Список доступных методов:

- [validateDevice: Поиск устройства в локальной сети](/docs/v3/device/payTerminal/validateDevice)
- [createPayTerminal: Создать банковский терминал](/docs/v3/device/payTerminal/createPayTerminal)
- [makePayment: Оплата заказа](/docs/v3/device/payTerminal/makePayment)
- [revertPayment: Возврат оплаты](/docs/v3/device/payTerminal/revertPayment)
- [x-report: Печать Х-отчета](/docs/v3/device/payTerminal/XReport)
- [z-report: Печать Z-отчета](/docs/v3/device/payTerminal/ZReport)
- [interrupt: Прерывание оплаты](/docs/v3/device/payTerminal/interrupt)
