## Начало работы

Чтобы работать с устройствами, включите переключатели **POS платформа** и **Device платформа** в настройках вашего приложения.

### Как подключить устройство на кассе

!> Чтобы тестировать **Device платформу**, вам нужно открыть кассу на
[iOS](https://apps.apple.com/us/app/poster/id691098784),
[Android](https://play.google.com/store/apps/details?id=com.joinposter&hl=ru) или
[Desktop](https://joinposter.com/mac) приложении.

Поиск устройств выполняется через Ethernet, для этого касса и внешнее устройство должны быть в одной локальной сети.

Для подключения вашего устройства зайдите в **Настройки → Устройства → Другое оборудование → Ваше приложение → Подключить устройство**.

### Подключение устройства через интеграцию 
!> Поиск работает по одному конкретному порту. Чтобы указать этот порт — напишите нам на почту contact@joinposter.com, чтобы мы изменили его для вашего приложения. Это может быть любой порт кроме 2222 и 2223, они используются для наших технических нужд.

Приложение проверяет все устройства в локальной сети, отправляя HTTP GET-запрос, например: *192.168.1.123:2224*.
Для передачи IP-адреса устройства в вашу интеграцию, ответ должен соответствовать одному из вариантов:
- Статус код 200
- Статус код 404 с тегом <html>
- Статус код 404 с любым JSON внутри
