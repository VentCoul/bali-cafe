# Web API

Раздел содержит методы для управления данными аккаунта Poster. 
Чтобы делать запрос к разделам Web API, укажите доступ в аккаунте разработчика соответсвующий префиксу раздела.
Например, чтобы сделать запрос к методу `/api/dash.getTransactions`, включите доступ к `dash`.
