# dash: Статистика

Методы для работы с разделом **Статистика**. Все методы данного раздела начинаются с «dash». Список доступных методов:

- [dash.getTransaction: Получить чек](/docs/v3/web/dash/getTransaction)
- [dash.getTransactions: Получить все чеки](/docs/v3/web/dash/getTransactions)
- [dash.getTransactionProducts: Получить товары в чеке](/docs/v3/web/dash/getTransactionProducts)
- [dash.getTransactionsProducts: Получить товары в нескольких чеках](/docs/v3/web/dash/getTransactionsProducts)
- [dash.getTransactionHistory: Получить историю чека](/docs/v3/web/dash/getTransactionHistory)
- [dash.getTransactionWriteOffs: Получить списание по чеку](/docs/v3/web/dash/getTransactionWriteOffs)
- [dash.getAnalytics: Получить статистику по продажам](/docs/v3/web/dash/getAnalytics)
- [dash.getProductsSales: Получить продажи по товарам](/docs/v3/web/dash/getProductsSales)
- [dash.getCategoriesSales: Получить продажи по категориям](/docs/v3/web/dash/getCategoriesSales)
- [dash.getClientsSales: Получить продажи по клиентам](/docs/v3/web/dash/getClientsSales)
- [dash.getWaitersSales: Получить продажи по официантам](/docs/v3/web/dash/getWaitersSales)
- [dash.getSpotsSales: Получить продажи по заведениям](/docs/v3/web/dash/getSpotsSales)
- [dash.getPaymentsReport: Получить статистику по дням/месяцам](/docs/v3/web/dash/getPaymentsReport)
