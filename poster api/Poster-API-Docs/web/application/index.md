- [access.deleteEntityExtras: Удалить дополнительные данные сущности](/docs/v3/web/application/deleteEntityExtras)
- [access.getInfo: Получить данные приложения](/docs/v3/web/application/getInfo)
- [access.getInfo: Изменить тарифный план приложения](/docs/v3/web/application/changeTariff)
