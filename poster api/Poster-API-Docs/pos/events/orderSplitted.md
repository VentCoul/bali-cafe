## orderSplitted: Разделение чека

```javascript
Poster.on('orderSplitted', (data) => {
	console.log(data);
})
```

Событие срабатывает после разделения чека.

### Ответ

В качестве аргумента в обработчик приходит объект `data` с такими свойствами

| Свойство | Значение                                       |
|----------|------------------------------------------------|
| order | Объект с заказом, который разделили |
| newOrderList | Массив ID новых заказов, которые появились после разделения |
