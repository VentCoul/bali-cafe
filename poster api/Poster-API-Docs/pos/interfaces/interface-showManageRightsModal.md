## interface.showManageRightsModal: Показать окно ввода пароля администратора

> Пример запроса: 
```javascript
Poster.interface.showManageRightsModal({
  askRights: true,
  enableLogging: false,
})
```

Метод вызывает окно ввода пароля администратора. Подходит для действий, которые невозможно выполнить без подтверждения администратора.

### Аргументы

В качестве аргумента принимается объект с параметрами:

| Аргумент      | Описание                                 |
|---------------|------------------------------------------|
| askRights     | true — вывести окно, false — не выводить |
| enableLogging | всегда false                             |

### Ответ

Функция возвращает `Promise` с результатом запроса.
