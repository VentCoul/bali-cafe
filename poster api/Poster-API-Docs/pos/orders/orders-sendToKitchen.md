## orders.sendToKitchen: Отправить бегунок по заказу

> Пример запроса:

```javascript
var result = await Poster.orders.sendToKitchen(1503219480866);

console.log(result); // { success: true }
```

Метод отправляет бегунки по заказу. Если в момент отправки бегунка не получилось отправить команду на принтер,
то ошибка будет отображаться только на кассе в заведении.


### Аргументы

| Аргумент | Описание                                   |
|----------|--------------------------------------------|
| orderId  | ID заказа (unix-timestamp в миллисекундах) |

### Ответ

Метод возвращает `Promise` результат которого объект со следующими свойствами:

| Свойство | Описание                                                                                             |
|----------|------------------------------------------------------------------------------------------------------|
| success  | Результат, удалось ли отправить бегунок: `true` — удалось, `false` — не получилось найти такой заказ |
