# Введение

На платформе Poster вы можете создавать любые приложения, например:

* **Синхронизация заказов и товаров между Poster и вашим сайтом**. Используйте API онлайн-заказов чтобы отправлять заказы с сайта на кассу. Кассир в заведении обработает и примет заказ, а вся статистика будет доступна в Poster. 
* **Специальные отчеты в админ-панели**. Если вам не хватает возможностей Poster вы можете создать приложение, которое встраивается в админ-панель и расширяет ее возможности. Не нужно переключаться между разными сайтами, все в одном месте. 
* **Чат с сотрудниками зала**. Владелец в админ-панели пишет про обновления системы мотивации, новости заведения. Сообщение приходят на кассу, каждый кассир сможет ознакомиться с ним.

### Возможности платформы

* **Делать запросы к Web API**. Получайте любые данные из аккаунта в Poster, создавайте товары, тех. карты и делайте продажи. 
* **Встраивать приложение в POS-кассу**. Платформа позволяет создавать утилиты для официантов и сотрудников заведений.
* **Встраивать приложение в админ-панель**. Расширяйте функционал бек-офиса Poster, встроив свое приложение прямо в админ-панель. 
* **Интегрировать ваши устройства или создавать виртуальные**. Таким образом вы сможете интегрировать, например, банковский терминал, или создать виртуальный фискальный принтер для работы с фискализацией. 

## Начало работы 

Чтобы адресовать API запросы в конкретный аккаунт, вам понадобится токен доступа. Если вы пишете приложение только для себя или знакомитесь с платформой, используйте токен **Личная интеграция** в вашем аккаунте в разделе **Доступ → Интеграции**. 

Если вы разрабатываете интеграцию для клиентов Poster, вам нужно создать **Приложение** в аккаунте разработчика. От его имени вы будете работать с системой и сможете опубликовать и продавать его в [каталоге интеграций Poster](/docs/v3/market/index).   


### Как создать приложение

Чтобы создать приложение:
 
1. [Зарегистрируйте](/signup) аккаунт разработчика или [войдите](/login) в существующий.
2. На странице **Poster for Developers → Создать приложение** заполните название, категорию и описание приложения и нажмите **Создать**
3. В разделе **Разработка** ваш аккаунт разработчика автоматически добавится в список тестирующих. Тестировщики видят приложение в каталоге до публикации.
4. `application_id` и `application_secret` вы найдете в настройках приложения, они понадобятся для [авторизации](/docs/v3/start/authApi).
