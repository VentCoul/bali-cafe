## Аккаунт разработчика

Чтобы начать розрабатывать свою интеграцию: 

1. Зарегистрируйте аккаунт разработчка по ссылке https://dev.joinposter.com/signup.
2. Перейдите в роздел **Все приложения → Poster for Developers**.
3. Нажмите в правом верхнем углу **Add application**.
4. Введите название приложение в блоке **Application name**.
5. Коротко опишите про приложение в **Short description**.
6. Выберите категорию приложения.
7. Нажмите **Create an application**.

После создания приложения открываются разделы для редактирования данных. 

### Настройки

**Application Id и Application Secret** – ваши личные данные для авторизации oAuth.

**Категории доступов** – категории доступов, которые планируете использовать для своего приложения.

**oAuth** – авторизация пользователей. При включении этого параметра добавьте redirect_url. 

**Manage-платформа** – включите, если планируете делать интеграцию в админ-панели.

**POS-платформа** – включите, если планируете делать интеграцию на кассе.

**Device-платформа** – включите, если планируете подключать устройства к вашей интеграции.

**URL для вебхуков** – ссылка для получения вебхуков. 

**Получать вебхуки по** – выберите сущности, по которым планируете получать вебхуки.

**Страница подключения** –  URL, по которому пользователь перейдет после нажатия на кнопку **Подключить** в каталоге приложений. Используйте при oAuth–авторизации. 

### Описание

Опишите приложение и добавьте логотип, чтобы пользователям было легче найти приложение в маркетплейсе и понять его функционал.

### Разработка

Страница для добавления аккаунтов, в которых будет работать приложение без ревью. Можно использовать для тестирования или для работы, если не планируете публиковать приложение маркетплейсе. 

После добавления аккаунта в Developers, в покдлюченном аккаунте перейдите в маркетплейс и подключите приложение.

### Публикация

Страница для передачи приложения на ревью нашим специалистам. Во время ревью мы проверим работу интеграции и ее влияние на Poster. Если есть ошибки или действия, которые ломают работу приложения — передадим обратную связь для исправления.

Чтобы ускорить процесс модерации:

* Протестируйте работу приложения перед подачей на ревью. Убедитесь, что приложение работает во всех необходимых сценариях пользователя.
* Предоставьте тестовые доступы к вашему сервису. Или уточните, что тестовых доступов у вас нет.
* Запишите видеоинструкцию с процессом подключения и работы с интеграцией. Она поможет будущим пользователям сориентироваться и повысит их вовлечённость. 
* Напишите список клиентов Poster, которые уже тестируют приложение.
* Заполните маркетинговое описание приложения, добавьте инструкцию для пользователей и цены для каждого региона.
