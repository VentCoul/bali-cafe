## Публикация в каталоге приложений


Релиз состоит из следующих этапов:

### 1. Аккаунт разработчика

[Зарегистрируйте аккаунт разработчика](/signup). В нем получите ключи для работы с API и будете управлять своим приложением. 
Аккаунт разработчика включает — это специальный аккаунт, который включает в себя функции обычного аккаунта Poster для тестирования вашей интеграции, а также Dev инструменты для создания приложения с целью его публикации в маркетплейсе. Доступы к этому аккаунту вы получите на почту после регистрации. 

Аккаунт разработчика бесплатный. Если срок действия аккаунта закончился, обратитесь в нашу службу поддержки с просьбой его продлить.


### 2. Разработка

Чтобы запуститься быстрее, следуйте [гайдлайнам интеграции](/docs/v3/market/guidelines/index). 
Установите временные рамки, за которые планируете закончить разработку. 

Мы поможем разобраться с продуктом. Вопросы по API пишите на [contact@joinposter.com](mailto:contact@joinposter.com). 
Находите описание работы продукта в [базе знаний Poster](https://support.joinposter.com/ru/) или задайте вопрос поддержке в чате на сайте.


### 3. Ревью и тестирование

Запишите видео с демонстрацией приложения.

Убедитесь, что ваше приложение работает корректно и соответствует [гайдлайнам Poster](/docs/v3/market/guidelines/index).
Посмотрите на интеграцию взглядом новичка.
Зарегистрируйте новый аккаунт Poster, подключите интеграцию и протестируйте все ее возможности, задавая себе следующие вопросы:

- Просто ли подключить интеграцию?
- Удобно ли ей пользоваться?
- Управляющий заведением или официант разберется как пользоваться приложением?

В аккаунте разработчика на странице Публикация отправьте приложение на ревью, в текстовом поле «Заметка про обновление» добавьте:

- Ссылку на видео с демонстрацией приложения.
- Тестовые доступы к вашему продукту, если будут нужны для тестирования.
- Любую дополнительную информацию, которая упростит процесс ревью приложения.

Убедитесь что:
  
- Заполнены описания для каталога.
- Инструкция содержит GIF с описанием подключения и работы интеграции.
- Приложение имеет доступ только к тем данным, которые нужны для работы.
- Код на вашем сервере работает в prod режиме, отключен debug.
- Будет плюсом, если кто-то из существующих клиентов Poster успешно работает с приложением.

Сотрудники Poster проверят, что интеграция не ломает работу Poster и не портит данные клиентов. 


### 4. Релиз

Публикуем интеграцию в каталоге. 
Помимо этого в Poster настроена реклама внутри продукта и автоматические сообщения в Intercom, которые рекламируют все категории приложений.

Как только клиент устанавливает приложение, вам на почту придет сообщение с его контактными данными. 
Звоните каждому лиду, чтобы увеличить конверсию.
