## Интеграция с PMS

Интеграция с PMS позволит владельцам отелей управлять ресторанами при отелях и взаимодействовать с комнатами и гостями отеля. При интеграции с PMS системой вы можете отправлять заказы из Poster в вашу PMS для отчетности, а также добавлять заказы из ресторана к общему счету гостя, если гость хочет оплатить все свои заказы при выезде с отеля.

### Основные шаги интеграции

#### Привязка гостя отеля к заказу

Когда клиент делает заказ в ресторане отеля, кассир создаёт заказ на кассе в Poster вручную. Если клиент является гостем отеля, нам нужно связать гостя отеля из PMS с заказом в Poster.

Добавляем на кассу кнопку **Добавить гостя** с помощью метода [interface.showApplicationIconAt](/docs/v3/pos/interfaces/interface-showApplicationIconAt). При нажатии на кнопку сработает событие [applicationIconClicked](/docs/v3/pos/events/applicationIconClicked), на это событие подвязываем [interface.popup](/docs/v3/pos/interfaces/interface-popup) в котором выводим список активных гостей из PMS:

```javascript
// Добавили кнопку 
Poster.interface.showApplicationIconAt({
  order: "Добавить гостя"
}); 

// Подписка на событие applicationIconClicked
Poster.on('applicationIconClicked', async () => {
  const guests = await yourFetchHotelGuestsMethod(); // тут ваш метод получения списка гостей из PMS
  Poster.interface.popup({
    width: 600,
    height: 500,
    title: 'Выбрать гостя'
  });
});// тут ваш метод вывода списка гостей
```

#### Выбор метода оплаты при закрытии заказа

После привязки гостя к заказу нам нужно отметить, как гость хочет оплатить заказ: оплатить его сейчас на кассе или добавить его в свой общий счет в отеле. Для этого используем ивент [beforeOrderClose](/docs/v3/pos/events/beforeOrderClose) для отображения всплывающего окна с выбором “Оплатить сейчас” или “Добавить в общий счет клиента”:

```javascript
// Тут нам нужно проверить, присваивали ли мы заказу клиента из PMS, если да, выводим попап
Poster.interface.popup({
  width: 400,
  height: 200,
  title: 'Выбор оплаты'
}); // В этом попапе выводим ваш фрейм с кнопками
```

При нажатии “Оплатить сейчас” пропускаем кассира в окно оплаты, при нажатии “Добавить в общий счет клиента”, методом [transactions.changeComment](/docs/v3/web/transactions/changeComment) добавляем в чек комментарий, что чек перенесен в общий счет и закрываем заказ методом [transactions.closeTransaction](/docs/v3/web/transactions/closeTransaction).

#### Кастомные методы оплаты

В вашей интеграции вы также можете использовать кастомные методы оплаты, добавив их самостоятельно. Так клиент сможет фильтровать заказы в статистике по разным методам оплаты, включая ваш кастомный. Это будет удобно в том случае, если клиенту нужно проверять, сколько заказов он передал для оплаты в PMS, а не закрыл сразу на кассе.

Используйте метод [settings.createPaymentMethod](/docs/v3/web/settings/createPaymentMethod), чтобы создать свой кастомный метод оплаты в аккаунте клиента. С помощью метода [settings.getPaymentMethods](/docs/v3/web/settings/getPaymentMethods) получите список всех методов и их id. Чтобы закрыть заказ с помощью вашего кастомного метода, в [transactions.closeTransaction](/docs/v3/web/transactions/closeTransaction) укажите id метода в параметр `payment_method_id`.

#### Обработка заказа после закрытия

Вне зависимости от того, оплатил гость заказ сейчас или добавил его к своему общему счету, нам нужно синхронизировать заказ в PMS для статистики. Для этого, когда отработал ивент [afterOrderClose](/docs/v3/pos/events/afterOrderClose), проверяем, присвоен ли заказу клиент из PMS. Если клиент присвоен — отправляем данные заказа в PMS при помощи API вашей PMS.
